## Submission

This is the first CRAN submission of orphacodes.

The package downloads the Orphanet nomenclature files from the RD-CODE
GitHub repository and the free Orphadata products. Examples and tests use
the bundled subset `orphamini` and need no network; the two tests that
download data are skipped on CRAN.
